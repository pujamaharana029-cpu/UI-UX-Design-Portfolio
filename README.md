## 📌 Project 1: Grocery Store App UI Design

A desktop grocery ordering interface designed in Figma.

### 🛠️ Tools Used

- Figma
- Wireframing
- High-Fidelity UI Design
- Prototyping

### 🎨 Design Process

Wireframing → High-Fidelity UI → Prototyping

### 📱 Screens Designed

1. Home Page
2. Vegetables Category Page
3. Product Details Page
4. Checkout Page
5. Payment Method Page
6. Order Confirmation Page

### 🔄 User Flow

Home → Vegetables → Product Details → Checkout → Payment → Order Confirmation
